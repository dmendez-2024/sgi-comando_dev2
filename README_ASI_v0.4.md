# SGI: Comando — ASI v0.4

Candidato UAT de **Asignaciones** sobre TER v1.0 FROZEN + COM v1.0 FROZEN.

v0.4 transforma la matriz en un spreadsheet operacional: timeline multi-semana, una celda por Turno completo, selección rectangular, Ctrl+C/V, TSV desde Excel, Fill, Undo/Redo y Copiar Día/Ciclo/Selección. La longitud del ciclo se consume de SIC: COM; UAT incluye 6-2 = 8 días y 5-2 = 7 días.
