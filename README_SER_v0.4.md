# SGI: Comando — SER v0.4

## Alcance
Nueva página **Servicios → Configuración → Puestos**.

### Ownership
- SIC: COM continúa como fuente de verdad de código, nombre, TIER, formato, rotación, turnos y estructura contractual del Puesto.
- SGI: Comando agrega la configuración operacional del Puesto.

### Configuración SGI por Puesto
- Tipo de Puesto: CAA / PAT / VIG / MIX.
- Descripción operacional.
- Ubicación seleccionada directamente sobre el plano ATS.
- Ocho habilidades requeridas mediante sliders 1–5.
- Economía de habilidades validada en frontend, backend y base de datos.
- Justificación cuando se alteran los valores sugeridos por tipo de Puesto.
- Permisos Requeridos visible como bloque no funcional / Próximamente.
- Guardar borrador y Guardar configuración.

### Economía de habilidades
1. Mínimo 1 punto por habilidad.
2. Máximo una habilidad con 5 puntos.
3. Máximo dos habilidades con 4 puntos.
4. Suma máxima total: 22 puntos.

### ATS
ATS v0.3.2 se conserva sin cambios funcionales en esta entrega.
