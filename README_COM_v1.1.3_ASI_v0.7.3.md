# SGI: Comando — COM v1.1.3 + ASI v0.7.3

Patch UAT sobre COM v1.1.2 / ASI v0.7.2.

## Cambios de esta entrega
- Kaibil es el contexto inicial de Asignaciones para Presidencia, Director Nacional, Director Zonal y Jefe Regional.
- El selector de Compañía permanece visible para esos perfiles aun cuando Kaibil esté seleccionada.
- Enviar transferencia usa modal SGI; no usa confirmación nativa del navegador.
- Aceptar / Rechazar / Anular mantienen los modales SGI ya incorporados.
- Sin cambio de base de datos; V18 permanece como última migración.

## UAT
Ejecutar `scripts/uat-start.ps1` y luego `scripts/uat-open.ps1`.
