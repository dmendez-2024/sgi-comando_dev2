# SGI: Comando — SER v0.8

UAT de **Servicios / Configuración → Consignas**.

Incluye Protocolos de Consignas versionables, una sola configuración vigente por Punto, Consignas con alcance a Todo el Punto o múltiples Puestos, Vigencia/Aplicación, reglas de cumplimiento, GPS opcional, ubicación ATS/coordenadas, Evidencias y Foto estándar preparada para VISINT.

Base: SER v0.7.3.1. No modifica verticales congeladas TER/COM/ASI.

## Arranque
```powershell
powershell -ExecutionPolicy Bypass -File .\repo\scripts\uat-start.ps1
```

## Abrir
```powershell
powershell -ExecutionPolicy Bypass -File .\repo\scripts\uat-open.ps1
```
