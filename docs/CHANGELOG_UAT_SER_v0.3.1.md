# SGI: Comando — CHANGELOG UAT SER v0.3.1

## Alcance
Pulido visual y de textos para la página **Configuración > ATS**.

## Cambios incluidos
- Se agrega el KPI **Índice de Riesgo de Punto** al extremo derecho del resumen superior.
- Se mejora la legibilidad de los KPI superiores para evitar cortes bruscos y saltos de línea incómodos.
- Se ordena el bloque **Archivo vigente** con mejor separación entre etiqueta y valor.
- **Hash** pasa a mostrarse como **Identificador**.
- **Checklist ATS** pasa a **Lista de verificación ATS**.
- **ADD / MODIFY / REMOVE** pasan a **AGREGADO / MODIFICADO / ELIMINADO**.
- Se mantiene todo el texto visible en español.

## Notas
- No hay cambio funcional de operación.
- ATS sigue siendo una página de configuración, no de visualización operativa en vivo.
