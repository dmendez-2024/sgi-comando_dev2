## Corrección sobre UAT v0.6

### Asignaciones
- Corregida la estructura general para acercarla al layout solicitado de referencia.

- Corregido el espacio en blanco superior no deseado dentro de la matriz.
- Ajustado el `freeze pane` para que no deteriore la composición inicial de la vista.
- Mejorado el comportamiento de rueda del mouse sobre la matriz para que el scroll vertical continúe desplazando la página.
- Refinada la banda Cliente / Punto para que el color continuo a lo largo de los días se vea mejor integrado visualmente.
- Se conserva el formato `Inicial.Apellido` en tarjetas y se mantiene eliminado el triángulo de advertencia.
