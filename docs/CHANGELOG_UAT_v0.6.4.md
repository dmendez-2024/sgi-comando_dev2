# SGI: Comando — CHANGELOG UAT v0.6.4

## Ajustes exclusivos de esta versión
- TIER se muestra como texto limpio (`TIER IV`, `TIER III`, etc.), sin caja, fondo, escudo ni gradiente.
- Tarjeta de asignación ajustada para priorizar el nombre corto completo (`D.Zambrano`) sin truncamiento.
- Al cambiar/abrir una semana, el scroll horizontal aterriza exactamente en el lunes de la semana seleccionada, inmediatamente después de `PUESTO / TURNO`.
- Sin otros cambios funcionales o visuales.
