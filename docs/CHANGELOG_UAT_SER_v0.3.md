# SGI: Comando — CHANGELOG UAT SER v0.3

## Alcance
- Se mantiene el listado de Servicios a nivel Cliente · Punto.
- Se mantiene la landing de Configuración del Punto.
- Se incorpora la nueva subpágina **Configuración > ATS**.

## ATS
- Header completamente en español.
- Resumen con archivo vigente, versión, última importación, cobertura, conflictos y estado.
- Bloque de archivo vigente con metadatos y acciones.
- Visor del plano con previsualización del punto.
- Panel de vinculación operacional para puestos, patrullas e hitos.
- Checklist ATS.
- Bloque de cambios detectados.
- Bloque de conflictos y observaciones.
- Historial ATS.

## Notas
- La página es de **configuración** y no de operación en vivo.
- El archivo manejado por esta vista queda congelado como **.ats**.
- Todo el texto visible en la página quedó en español.
