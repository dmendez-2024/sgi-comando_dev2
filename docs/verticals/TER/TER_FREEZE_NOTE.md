## Dependencia CORE
La disponibilidad productiva de geometrías y versionamiento territorial es responsabilidad de CORE. Mientras CORE real no exponga el contrato, el adaptador `CORE LOCAL · UAT` puede conservar una referencia visual de Ecuador exclusivamente para pruebas.

Ese fallback no cambia ni debilita la regla congelada: el producto final renderiza desde geometrías CORE.

## Regla de cambio
TER no se modifica durante el trabajo de COM. Cualquier cambio futuro requiere:
1. solicitud explícita;
2. nuevo ID de decisión;
3. versión TER > 1.0;
4. análisis de impacto y regresión.
